# Speech Emotion Recognition

## Description

This project analyzes spoken language and identifies the emotion expressed in the speech.

## Supported Emotions

- Happy
- Sad
- Angry
- Neutral

## Technologies Used

- Python
- SpeechRecognition
- Google Speech Recognition
- Natural Language Processing
- Microphone

## How It Works

1. The microphone captures speech.
2. Speech Recognition converts the audio into text.
3. The recognized text is analyzed for emotion-related words.
4. The system classifies the emotion.
5. The detected emotion is displayed.
